# BUG-008 — Repository missing UI components / static assets required to run

| Field | Value |
|-------|--------|
| Severity | **Medium** |
| Priority | Medium |
| Status | Open (mitigated locally for QA) |
| Environment | Fresh clone of The-Garrison |
| Module | Packaging / testability |

## Summary

`index.php` and other pages `include` files under `components/` (header, footer, home, menu, …) and expect template assets, but those paths were not present in the GitHub tree. A fresh clone cannot render the marketed UI from the README screenshots.

## Steps to reproduce

1. Clone the repository.
2. Start Docker / PHP.
3. Open `/login.php` or `/index.php`.
4. Observe missing include warnings / broken layout.

## Expected

All runtime dependencies committed (or documented as a submodule / build step).

## Actual

Missing `components/*.php` and front-end assets; README screenshots do not match what the clone serves.

## Mitigation used for this portfolio

Minimal Bootstrap stubs under `src/components/` so auth, admin, and reservation flows could be exercised for testing. Full visual template remains out of scope for the QA pack.
