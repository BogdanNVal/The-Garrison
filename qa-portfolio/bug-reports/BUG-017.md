# BUG-017 — Admin cannot open the reservation page

| | |
|--|--|
| Severity | Low |
| Priority | Low |
| Status | Open |
| Build | Current main |
| Area | Roles / UX |
| Case | RES-12 |

## Summary

Reservation requires a **customer** session (`user_id`). An admin session only has `admin_id`. Opening `/rezervare.php` as admin redirects to `login.php`, which then sends the admin to `secure.php`. The header also hides “Rezerva o masa” for admins.

So admins have no path to book a table without logging out and using a customer account.

## Steps

1. Log in as `admin@garrison.com`.
2. Open `/rezervare.php` (or follow redirects).

## Expected

Documented product behavior — either allow admin booking, or a clear “admins can’t book here” page.

## Actual

`302` → `login.php` → `302` → `secure.php`. Lands back on admin panel with no explanation.
