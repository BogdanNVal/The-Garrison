# BUG-002 — Reservation search works without login

| | |
|--|--|
| Severity | Critical |
| Priority | High |
| Status | Open |
| Build | Local, http://127.0.0.1:8080 |
| Area | Admin search |
| Case | SRCH-07 |

## Summary

`livesearch.php` returns reservation details even if you’re not logged in. The search page itself is protected, but the AJAX endpoint is not.

## Steps

1. Log out (or use curl with no cookies).
2. `curl -X POST http://127.0.0.1:8080/livesearch.php -d "input=QA"`
3. Check the response.

## Expected

Redirect / forbidden / empty. No names, dates, table ids.

## Actual

Full HTML table with reservation data.

## Screenshot

![unauthenticated search](../docs/screenshots/BUG-evidence-live.png)

## Notes

`search.php` checks admin session. `livesearch.php` does not — anyone who knows the URL can hit it.
