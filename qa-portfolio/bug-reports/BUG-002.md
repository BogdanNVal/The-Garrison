# BUG-002 — Reservation search works without login

| | |
|--|--|
| Severity | Critical |
| Priority | High |
| Status | **Fixed** (retested on current main) |
| Build | Current main, http://127.0.0.1:8080 |
| Area | Admin search |
| Case | SRCH-07 |

## Summary (original)

`livesearch.php` returned reservation details without an admin session. The search page was protected; the AJAX endpoint was not.

## Retest on current main

```bash
curl -i -X POST http://127.0.0.1:8080/livesearch.php -d "input=QA"
```

## Expected

Forbidden / empty. No names, dates, table ids.

## Actual (now)

HTTP `403` with `FORBIDDEN`. No reservation data in the body.

## Notes

`livesearch.php` now starts the session, checks admin login, and escapes output. Keep SRCH-07 in regression.
