# BUG-011 — Can save a menu item with price “abc” (shows as 0)

| | |
|--|--|
| Severity | High |
| Priority | High |
| Status | Open |
| Build | Local, http://127.0.0.1:8080 |
| Area | Menu admin |
| Cases | MENU-18 |

## Summary

On Add product I sent a non-numeric price (`abc`) with otherwise valid fields. The item was created and the price in the DB is `0.00`. Tried `12abc` too — that one saved as `12.00`.

## Steps

1. Log in as admin.
2. Open Add product.
3. Fill name, description, category, valid image.
4. Set price to `abc` (I used a direct POST so the browser number field wouldn’t block it).
5. Submit.
6. Check the admin menu / `meniu` table.

## Expected

Error, nothing saved.

## Actual

Redirect to admin panel. In DB:

```
AbcPrice     0.00
TwelveAbc   12.00   (from pret=12abc)
```

## Notes

Looks like only “price must be > 0” is checked, so garbage strings slip through and end up as zero. Similar to BUG-003, different input.
