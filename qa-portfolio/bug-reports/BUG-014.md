# BUG-014 — Text file accepted as a menu image if it ends in .png

| | |
|--|--|
| Severity | Medium |
| Priority | Medium |
| Status | Open |
| Build | Local, /add.php |
| Area | Menu admin |
| Case | MENU-21 |

## Summary

I uploaded a plain text file renamed to `fake.png`. Add product accepted it and saved it under the menu images folder. It’s not a real image.

## Steps

1. Create a file `fake.png` whose contents are just `not an image`.
2. Log in as admin.
3. Add product: valid name, price, description; attach that file.
4. Submit.
5. Open the saved file (or check with a file-type tool).

## Expected

“Wrong format” / reject. No product, or at least no fake image stored.

## Actual

Product created. Saved file is still text (`fake.png: ASCII text`).

## Notes

Looks like only the extension is checked (jpg/png/jpeg), not whether the file is actually an image.
