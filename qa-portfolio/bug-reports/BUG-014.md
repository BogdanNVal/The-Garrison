# BUG-014 — Non-image file accepted if extension is png/jpg/jpeg

| | |
|--|--|
| Severity | Medium |
| Priority | Medium |
| Status | Open |
| Build | Current main, `/add.php` |
| Area | Menu admin / uploads |

## Summary

Upload validation only checks the file extension. A plain-text file renamed to `.png` is accepted, moved into `assets/img/menu/`, and linked as a menu image. No `getimagesize` / MIME / content check.

## Steps

1. Create a text file `fake.png` with body `not an image`.
2. As admin, Add product with that file, valid name/price/description.
3. Inspect the saved file (`file` command / browser image).

## Expected

Reject non-image content.

## Actual

Product created. On disk: `fake.png: ASCII text`.

## Notes

Pairs with BUG-013 (overwrite). Extension whitelist alone is not enough.
