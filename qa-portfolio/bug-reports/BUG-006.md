# BUG-006 — Admin UI typo: “rezevari”

| Field | Value |
|-------|--------|
| Severity | **Low** |
| Priority | Low |
| Status | Open |
| Environment | Local · `/secure.php`, `/search.php` |
| Module | Admin UI |
| Related case | SRCH-09 |

## Summary

Button/label text reads **“Verifica rezevari”** (missing **r**). Correct Romanian: **“rezervari”**.

## Steps to reproduce

1. Log in as admin.
2. Open `/secure.php`.
3. Read the link styled `btn-book-a-table`.

## Expected

“Verifica rezervari” (or English equivalent if UI is localized).

## Actual

“Verifica rezevari”.

## Notes

Cosmetic, but visible on primary admin navigation; good example of linguistic/UI polish bugs in a QA report set.
