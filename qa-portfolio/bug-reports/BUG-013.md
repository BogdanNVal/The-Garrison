# BUG-013 — Uploading a menu image can overwrite an existing file

| | |
|--|--|
| Severity | High |
| Priority | High |
| Status | Open |
| Build | Local, /add.php |
| Area | Menu admin |
| Case | MENU-20 |

## Summary

New product images keep the original filename. I uploaded a small PNG named `menu-item-1.png` and it replaced the seed image that other dishes already use.

## Steps

1. Note how `menu-item-1.png` looks on the public menu (or its file size / checksum).
2. Log in as admin.
3. Add a product, attach any image but name the file `menu-item-1.png`.
4. Submit.
5. Check the file on disk / dishes that pointed at that path.

## Expected

New upload gets its own name, or a clear error if the name is taken. Old images stay put.

## Actual

`menu-item-1.png` on disk was replaced by my upload. Anything still using that path shows the new picture.

## Notes

Easy to miss if you always upload uniquely named photos. I hit it on purpose with the seed filename.
