# BUG-013 — Menu image upload can overwrite existing files

| | |
|--|--|
| Severity | High |
| Priority | High |
| Status | Open |
| Build | Current main, `/add.php` |
| Area | Menu admin / uploads |

## Summary

Uploads are saved as `assets/img/menu/<client-original-filename>` after `basename()` only. There is no unique rename. Uploading a file named `menu-item-1.png` **replaces** the seed/template asset used by other menu rows.

## Steps

1. Note MD5 (or contents) of `src/assets/img/menu/menu-item-1.png`.
2. As admin, Add product with a different image but set the filename to `menu-item-1.png`.
3. Re-check the file on disk / public menu images that pointed at that path.

## Expected

Stored under a unique name (or reject collisions); existing assets untouched.

## Actual

File on disk was replaced (MD5 changed from seed to the new upload). Product row points at the same path.

## Notes

`basename()` blocks `../` traversal, but overwrite / shared filename remains. Related: BUG-014 (content not verified).
