# BUG-003 — Can save menu items with price 0 or negative

| | |
|--|--|
| Severity | High |
| Priority | High |
| Status | **Fixed** (retested on current main) |
| Build | Current main, admin logged in |
| Area | Menu admin |
| Cases | MENU-07, MENU-08 |

## Summary (original)

On Add product, price `0` or `-5` still got saved even when a price error message appeared.

## Retest on current main

1. Log in as admin.
2. Open Add product.
3. Submit with price `-5` or `0` and otherwise valid fields (or trigger validation without upload).

## Expected

Blocked. No new row in `meniu`.

## Actual (now)

Shows `Adauga un pret corect`. No item created for those prices.

## Notes

`add.php` sets `$error = true` when `$pret <= 0` and skips the insert. Keep MENU-07/08 in regression.
