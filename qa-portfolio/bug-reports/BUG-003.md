# BUG-003 — Can save menu items with price 0 or negative

| | |
|--|--|
| Severity | High |
| Priority | High |
| Status | Open |
| Build | Local, admin logged in |
| Area | Menu admin |
| Cases | MENU-07, MENU-08 |

## Summary

On Add product, price `0` or `-5` still gets saved. The form can show a price error message, but the item is created anyway.

## Steps

1. Log in as admin.
2. Open Add product.
3. Fill name, description, category, valid image.
4. Set price to `-5` (also tried `0`).
5. Submit.

## Expected

Blocked. No row in `meniu`.

## Actual

Redirect to admin menu. In DB:

```
1  Negative Price  -5.00
2  Zero Price       0.00
```

Looks like the price check sets the error text but doesn’t stop the submit (update form seems stricter).
