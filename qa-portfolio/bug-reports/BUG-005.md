# BUG-005 — Delete product always kicks admin out

| | |
|--|--|
| Severity | High |
| Priority | High |
| Status | **Fixed** (retested on current main) |
| Build | Current main, admin session (Remember me off) |
| Area | Menu admin |
| Cases | MENU-12, MENU-13 |

## Summary (original)

Clicking Delete as admin redirected to home instead of the confirm page when Remember me was off (`delete.php` did not start the session the same way as Update).

## Retest on current main

1. Log in as admin (don’t tick Remember me).
2. Open `/delete.php?id=1` (or click Delete on a product).

## Expected

Confirm screen (“Esti sigur…”).

## Actual (now)

Confirm page loads with the delete form. Session is recognized.

## Notes

`delete.php` now calls `session_start()` before the admin check. Keep MENU-12/13 in regression.
