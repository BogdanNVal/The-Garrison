# BUG-005 — Delete product always kicks admin out

| | |
|--|--|
| Severity | High |
| Priority | High |
| Status | Open |
| Build | Local, admin session (Remember me off) |
| Area | Menu admin |
| Cases | MENU-12, MENU-13 |

## Summary

Clicking Delete as admin doesn’t open the confirm page. I get sent back to the home page instead, so I can’t delete items with a normal session.

## Steps

1. Log in as admin (don’t tick Remember me).
2. From the menu, click Delete on a product (or open `/delete.php?id=1`).
3. Check what page you land on.

## Expected

Confirm screen (“Esti sigur…”).

## Actual

302 to `index.php`. Same session can still open Update for that product.

## Screenshot

![delete redirects](../docs/screenshots/BUG-evidence-delete.png)

## Notes

Delete page doesn’t start the PHP session the same way Update does. If Remember me is on it might still work, which makes it easy to miss.
