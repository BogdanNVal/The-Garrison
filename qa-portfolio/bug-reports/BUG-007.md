# BUG-007 — Add product errors don’t show on screen

| | |
|--|--|
| Severity | Medium |
| Priority | Medium |
| Status | Open |
| Build | Local + code check on add.php |
| Area | Menu admin |
| Case | MENU-16 |

## Summary

When adding a product fails in the backend, the page doesn’t show the error. The code writes one variable name and the template reads another.

## Steps

1. Open `add.php` and compare the error variable used after `add()` with the one in the alert block.
2. Or force an add failure and watch the UI.

## Expected

Red alert with the real error message.

## Actual

No useful message (empty / wrong variable).

## Notes

Sets `$err_msg`, template checks `$error_msg`. Easy mismatch, bad for the admin when something goes wrong.
