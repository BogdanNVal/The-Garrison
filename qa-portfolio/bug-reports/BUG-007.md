# BUG-007 — Add product errors don’t show on screen

| | |
|--|--|
| Severity | Medium |
| Priority | Medium |
| Status | **Fixed** (retested on current main) |
| Build | Current main + code check on add.php |
| Area | Menu admin |
| Case | MENU-16 |

## Summary (original)

When adding a product failed in the backend, the page didn’t show the error. The code wrote `$err_msg` and the template read `$error_msg`.

## Retest on current main

1. Open `add.php` and compare the error variable after `add()` with the alert block.
2. Confirm both use `$err_msg` and the alert calls `htmlspecialchars($err_msg)`.

## Expected

Red alert with the real error message when the class/DB layer fails (or when image move fails).

## Actual (now)

Variable names match (`$err_msg`). Upload-permission failures also set `$err_msg` with a clear message.

## Notes

Keep MENU-16 in regression if you force a backend failure path.
