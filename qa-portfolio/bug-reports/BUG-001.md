# BUG-001 — Can book a table in the past

| | |
|--|--|
| Severity | High |
| Priority | High |
| Status | Open |
| Build | Local Docker, http://127.0.0.1:8080 |
| Area | Reservations |
| Case | RES-06 |

## Summary

Reservation accepts old dates (tried `2020-01-01`) and saves them in the DB.

## Steps

1. Log in as a customer.
2. Go to Rezervare.
3. Party size `2`.
4. Date `2020-01-01`.
5. Submit.

## Expected

Error, nothing saved.

## Actual

Redirects to home. Row in `rezervari`:

```
id=1  nume=QA Tester  data_rezervare=2020-01-01  nr_persoane=2
```
