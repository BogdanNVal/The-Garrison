# BUG-001 — Can book a table in the past

| | |
|--|--|
| Severity | High |
| Priority | High |
| Status | **Fixed** (retested on current main) |
| Build | Current main, http://127.0.0.1:8080 |
| Area | Reservations |
| Case | RES-06 |

## Summary (original)

Reservation accepted old dates (e.g. `2020-01-01`) and saved them in the DB.

## Retest on current main

1. Log in as a customer.
2. Go to Rezervare.
3. Party size `2`, date `2020-01-01`, submit (or POST the same via curl).

## Expected

Error, nothing saved.

## Actual (now)

Form shows `Nu puteti rezerva o data din trecut`. Date input has `min` set to today. No row for `2020-01-01` in `rezervari`.

## Notes

Server-side check was added in the project-fix commit on main. Keep RES-06 in regression.
