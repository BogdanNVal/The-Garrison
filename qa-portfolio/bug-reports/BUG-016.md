# BUG-016 — Reservation accepts party size “2.5” and “2abc”

| | |
|--|--|
| Severity | Medium |
| Priority | Medium |
| Status | Open |
| Build | Local, /rezervare.php |
| Area | Reservations |
| Case | RES-13 |

## Summary

The form’s number field stops you in the UI, but a direct POST with `nr_persoane=2.5` or `2abc` still creates a reservation. Both ended up stored as `2`.

## Steps

1. Log in as a customer.
2. POST to Rezervare with party size `2.5` and a future date (same again with `2abc`).
3. Check `rezervari`.

## Expected

Error, nothing saved. Only whole numbers 1–6.

## Actual

Redirect to home. Rows created with `nr_persoane=2` for both payloads.

## Notes

Browser `min`/`max` aren’t enough if the server accepts messy strings.
